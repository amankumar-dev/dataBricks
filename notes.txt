Databricks?
Managed spark in the cloud + Tools for data engineering, data science & ML

What does Databricks do?
-> Manages spark cluster: We didn't configure server manually.
-> Web based notebooks: Browser me python, sql, scala, R likh saktey hai.
-> Delta lake support: ACID transaction, Schema Enforcement, Better performance.
-> Integration with cloud: Databricks run krta hai AWS, Microsoft Azure, Google Cloud Services. 

Serverless Compute?
Serverless compute means we don't manage servers - the platform manages everything for you.

We can use pyspark but in real production we need to manage cluster setup, workernodes, scaling, failures etc. Doing this manually on AWS/Azure with spark is painfull. But Databricks gives extra no mannual cluster setup, Auto scaling etc.

.explain method?
It shows how spark will execute your query. Not the result but the execution plain
-> df.explain(: Shows basic physical plan
-> df.explain(True)):  Shows parsed llogical plan, Analyzed plan, Optimized plan, Physical plan
-> df.explain('formatted'): Clean readable format.

Parition Vs parallelism?
-> Partition: It means how much chunks of data
    df.rdd.getNumPartitions()               # Get number of Partition
    df.repartition(4)                       # Set the Partition number
    df.coalesce(2)                          # Reduce Partition
-> Parallelism: It means how much task can be performed once.
    spark.sparkContent.defaultParalleism        # Get parallel value

Managed VS External tables?
-> Managed: Databricks controls data + Metadata, sotres data automatically, chooses storeage location, Manage everthing, If we drop tables data will be lost
    df.write.saveAsTable('movie')
-> External: Databricks controls metadata only, data is outside, Data is stored in defined path, Drop table still data exists.
    df.write.option('path','defined/path/as/your/own').saveAsTable('movie')

Medellion Architecture?
It is a way to organize data into layers for better quality and processing
-> Bronze layer(Raw data): This is  raw unprocessed data, directly ingested from resorce, contains errors, nulls, duplicates, no cleaning.
-> Silver layer(Cleaned Data): This is processed and cleand data i.e. remove nulls, fix datatypes, deduplicates, Basic transformations.
-> Gold layer(Business Ready): This is final, aggregated edata i.e. ready for dashboards, KPIs, metrics, Reporting tables.

Cluster?
Cluster is like a team of computers working together. It has 2 main parts i.e. Driver nodes(brain of the cluster, sends tasks), Worker nodes(do actual works)
=There are two types of cluster:

-> Job cluster: Ek time set kr dengey ya ek condition wo hit hoga to khud cluster banaega aurclean krke save karega fir cluster remove kr dega
